# Clarivo scoring rubric

This document defines the initial scoring dimensions. Detailed score anchors
and human-evaluation examples will be refined before the content evaluator is
implemented.

## Evaluation rule

Every score must follow:

```text
Evidence
→ Interpretation
→ Score
```

A score without supporting transcript or timing evidence is not actionable.

## Delivery

### Fluency

Supporting signals include filler rate, pause patterns, repetition, false
starts, and self-corrections. These signals are measured separately before they
are interpreted as good or bad.

### Pace

Supporting signals include raw words per minute, active words per minute,
speaking duration, silence duration, and pause statistics.

## Content

### Relevance

Measures whether the response directly answers the prompt and remains on topic.

Initial five-point anchor:

- 5: Directly and fully answers the prompt.
- 4: Answers directly with minor unnecessary background.
- 3: Answers the prompt but contains substantial digressions.
- 2: Answers only part of the prompt.
- 1: Barely addresses or does not address the prompt.

### Structure

Measures whether the answer has an identifiable main point and a logical
exercise-appropriate progression.

### Conciseness

Measures whether the answer communicates its useful content without redundant
phrasing or repeated conclusions.

### Coherence

Measures whether ideas connect logically and the listener can follow the train
of thought.

## Exercise-specific outlines

- Opinion: Point → Reason → Example → Conclusion
- Interview: Situation → Task → Action → Result
- Technical explanation: What → How → Example → Why
- Summary: Main idea → Key supporting points, without major fabrication

## Coaching constraint

The product should select the top three improvements rather than exposing every
detected issue at once.
